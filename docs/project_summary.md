# Project Summary

This project analyzes Twitter discourse during the 2019 Australian Federal Election using NLP, sentiment analysis, topic modeling, predictive modeling, and transformer-based classification.

## Research Questions

1. What topics dominated election-related tweets?
2. How did public sentiment and emotion change around Election Day?
3. Which tweet-level features were related to engagement?
4. Do emotions and sentiment explain virality?
5. How do classical NLP and transformer models compare?

## Main Analytical Components

- Data cleaning and text preprocessing
- Sentiment polarity and subjectivity with TextBlob
- Emotion extraction using NRC emotion categories
- Word frequency and word cloud analysis
- LDA topic modeling
- Engagement modeling for retweets and favorites
- Temporal analysis across pre-election, Election Day, and post-election periods
- Classical NLP and transformer-based model comparison

## Main Findings

Tweet activity peaked on May 18, 2019, which was Election Day. Sentiment was mostly neutral with a slight positive tendency. Emotional tweets received more engagement than neutral tweets, but emotion scores themselves had weak direct correlations with retweets and favorites. Hashtags, URLs, and mentions were more useful predictors of engagement than sentiment or emotion. Topic-level emotion analysis added more nuance by showing that policy-related topics carried more anger and fear, while voting and election culture topics were more positive and anticipatory.

## Limitations

- NRC emotion scores are sparse for short tweets.
- TextBlob labels are rule-based and may not reflect true human sentiment.
- Engagement models do not include important author-level features such as follower count.
- Transformer evaluation is limited when the benchmark labels are generated by simpler lexicon-based methods.

## Future Work

- Add human-labeled sentiment data as a gold standard.
- Include author metadata such as follower count and verified status.
- Fine-tune transformer models on political tweets.
- Compare model results across different countries or election cycles.
